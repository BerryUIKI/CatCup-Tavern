data/

データはファイルのまま

キャラクターはメタデータを画像に埋め込んだ PNG カード、または素の JSON。チャットは JSONL で一行にひとつのメッセージ、スワイプも分岐もそのまま入っています。世界観設定、プリセット、設定はすべて JSON。バックアップはフォルダをコピーするだけ、引っ越しもフォルダをコピーするだけ、中身はどれもエディタで開けます。

data/
├── characters/     カード（PNG または JSON）
├── chats/          チャットごとに 1 つの JSONL
├── worlds/         世界観設定
├── presets/        プロンプトプリセット
├── groups/         グループの部屋
├── user/images/    生成した画像
├── secrets.json    API キー（サーバー専用）
└── settings.json   プロバイダー、ペルソナ、プロファイル

インポート先に別のアプリのデータフォルダを指定すれば、カード、チャット、世界観設定、プリセットが一度に移ります。独自形式への変換はありません。

data/

できること

  • data/characters/ キャラクターとグループ PNG、JSON V2/V3、CharX のカードに対応。ひとりと話すのも、五人を同じ部屋に入れてそれぞれの挨拶、アイコン、発言順を持たせるのも自由です。 対応
  • data/worlds/ 世界観設定 主キーと副キー、再帰、重み付きのインクルージョングループ、スティッキーとクールダウン、トークン上限、そしてすべての挿入位置。どの項目がなぜ発動したかを示すインスペクターつき。 対応
  • data/presets/ プロンプトプリセット OpenAI プリセットを取り込み、プロンプトの順序を入れ替え、無効にし、チャット内挿入へ移して深さ・順序・ロールを個別に指定できます。 対応
  • data/chats/ チャットと分岐 推論を別枠で受け取るストリーミング返信、スワイプ、編集、そして任意のメッセージからの分岐。元のチャットはそのまま残ります。 対応
  • data/chats/ · summary 要約メモリ ローリング要約はチャットファイルの中、要約しているメッセージの隣に置かれます。自分で編集しても、返信のたびに更新させてもかまいません。 対応
  • user/images/ 音声と画像 ブラウザの音声、または OpenAI 互換の音声エンドポイント。画像は Automatic1111、ComfyUI、OpenAI 互換のエンドポイントから、キャラクターごとに保存します。 対応
  • data/secrets.json プロバイダー 五つのリクエストプロトコルで OpenAI、OpenRouter、Anthropic、Gemini、Ollama、そして自分で入力した互換エンドポイントをカバーします。キーはサーバーにとどまります。 対応
  • quickreplies/ クイックリプライ 入力欄の上にボタン列として並ぶセット。七つのコマンドをつなげられますが、自動実行とコンテキストメニューはまだありません。 一部対応
  • Import 他のアプリからの取り込み 別のアプリのデータフォルダを走査し、何が見つかったかを確認してから、キャラクター、チャット、世界観設定、プリセットを一度にコピーします。 対応
1 → 5

ひとつの返信ができるまで

  1. 組み立て プリセットの順にプロンプトを組み立て、ペルソナ、キャラクター、シナリオをそれぞれの枠に入れます。
  2. 世界観を走査 世界観設定のキーを直近の会話に照らし、インクルージョングループと時間効果が発動する項目を決めます。
  3. トークンを配分 OpenAI、Claude、Gemini のモデルごとのトークナイザーで、文脈をモデルの予算に収めます。
  4. プロバイダーへ 有効なプロバイダーへリクエストを一通。そのプロバイダー自身のプロトコルで送ります。
  5. ストリーム トークンは SSE で届きます。メッセージを保存するのはサーバー、描くだけなのがページです。
—

まだできないこと

早期アクセスのソフトウェアです。インストールの前に知っておきたい不足を挙げます。

  • 手入力のスラッシュコマンドとスクリプト。/send hello のような行はただの文章としてモデルに渡ります。コマンドを実行するのはクイックリプライのボタンだけです。
  • 他のクライアント向けの拡張機能。ひとつも読み込めません。
  • 添付と画像入力。ファイルのアップロードも、画像の送信もできません。
  • ベクターメモリ。長い会話は予算に合わせて切り詰められ、長期記憶は要約だけです。
  • macOS と Linux。どちらもパッケージでき、CI もビルドしますが、公開しているのは Windows だけで、どちらも実際には動かしていません。
  • 署名のないインストーラー。ダウンロードした複製には SmartScreen が一度警告します。入手元はリリースページだけにしてください。

完全な一覧はこちら 制限事項 · 形式の互換性.

install

インストール

Windows

最新リリースからインストーラーをダウンロードして実行します。ユーザー単位で入り、管理者権限も別途の Node も不要。データは %APPDATA%\dev.catcup.tavern に置かれます。署名がないため SmartScreen が一度警告し、発行元は表示されません。「詳細情報 → 実行」を選んでください。

インストーラーをダウンロード 直接ダウンロード：このバージョンのインストーラーを GitHub から取得します。

CatCup.Tavern_0.4.0_x64-setup.exe · すべてのリリース

ソースから Web 版・LAN 版を起動

Node.js 22.13 以降と pnpm 11 が必要です。初回起動時にアクセスパスワードを設定します。設定できるのはサーバーを動かしているマシンだけです。

pnpm install
pnpm dev
CATCUP_HOST=0.0.0.0 pnpm start

LAN で使うならすべてのインターフェースにバインドします。関門はパスワードだけです。 そのあと http://localhost:5173 を開きます。 TLS は内蔵していません。信頼できるネットワークの外では、リバースプロキシか VPN の内側に置いてください。

インストールを移す

CATCUP_DATA_DIR でデータフォルダを別の場所に向けられます。別のマシンへ移すときも、デスクトップ版が既存のライブラリを引き継ぐときも、この方法です。
