# 设计需求（给设计师）

当前品牌素材（图标 + README banner）已完成。以下是后续可排期的项目，优先级从上到下。

## 1. 社交预览图（og:image）

- 尺寸 1280×640 PNG，用于链接分享卡片（GitHub About 链接、Discord 等）。
- 内容：沿用深色版的横版锁版（图标 + 「CatCup / Tavern」字标），背景咖啡色 `#3a241c` 或更深的 `#17100a`，四角留白安全区约 64px。
- 文字无需额外信息；如需可以加一行小字 "SillyTavern-compatible AI roleplay client"（奶油色，字重小）。

## 2. 空状态插画（应用内，两幅）

- 风格与图标一致：单色奶油 `#fdf4e2` 或咖啡 `#3a241c` 线条，粗描边，手绘感。
- 用途与尺寸：显示在深色界面中，约 200×160 px，透明背景。
  1. **空图书馆**：歪头疑惑的小猫看着一个空书架或空茶杯。
  2. **暂无聊天**：小猫趴在翻开的书或空白对话框上打盹。

## 3. 应用图标的小尺寸变体（16/24/32 px）

- 当前图标在 16px 下细节会并成一团。若有精力，请提供一版**简化图形**（只保留圆盘 + 猫头轮廓 + 杯沿），用于 ico 内嵌的小尺寸槽位；48px 及以上仍用现有母版。
