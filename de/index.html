Deine Daten bleiben Dateien

Charaktere sind PNG-Karten mit ihren Angaben im Bild, oder schlichtes JSON. Chats sind JSONL, eine Nachricht pro Zeile, Swipes und Abzweigungen inklusive. Lorebooks, Presets und Einstellungen sind JSON. Ordner kopieren heißt sichern, Ordner kopieren heißt umziehen, und jede Datei lässt sich in einem Editor öffnen.

data/
├── characters/     Karten, PNG oder JSON
├── chats/          ein JSONL pro Chat
├── worlds/         Lorebooks
├── presets/        Prompt-Presets
├── groups/         Gruppenräume
├── user/images/    erzeugte Bilder
├── secrets.json    API-Schlüssel, nur serverseitig
└── settings.json   Anbieter, Personas, Profile

Richte den Import auf den Datenordner einer anderen App, und Karten, Chats, Lorebooks und Presets kommen in einem Schritt herüber. Nichts wird in ein eigenes Format umgewandelt.

data/

Was es kann

  • data/characters/ Charaktere und Gruppen PNG-, JSON-V2/V3- und CharX-Karten. Sprich mit einem Charakter oder setz fünf in einen Raum, jeder mit eigenen Begrüßungen, Avataren und Redeordnung. Funktioniert
  • data/worlds/ Lorebooks Primär- und Sekundärschlüssel, Rekursion, gewichtete Einschlussgruppen, Haft- und Abklingzeiten, das Token-Budget und jede Einfügeposition, dazu ein Prüfer, der zeigt, warum ein Eintrag gezündet hat. Funktioniert
  • data/presets/ Prompt-Presets Ein Preset importieren, Prompts umsortieren oder abschalten, oder einen in eine Chat-Einfügung verschieben, mit eigener Tiefe, Reihenfolge und Rolle. Funktioniert
  • data/chats/ Chats und Abzweigungen Gestreamte Antworten mit getrennt aufbewahrtem Denken, Swipes, Bearbeiten und eine Abzweigung aus jeder Nachricht, die den ursprünglichen Chat unangetastet lässt. Funktioniert
  • data/chats/ · summary Zusammenfassungsgedächtnis Eine rollierende Zusammenfassung, gespeichert in der Chat-Datei, direkt neben den Nachrichten, die sie zusammenfasst. Selbst bearbeiten oder nach Antworten aktualisieren lassen. Funktioniert
  • user/images/ Sprache und Bilder Browserstimmen oder ein OpenAI-kompatibler Sprach-Endpunkt. Bilder von Automatic1111, ComfyUI oder einem OpenAI-kompatiblen Endpunkt, pro Charakter aufbewahrt. Funktioniert
  • data/secrets.json Anbieter Fünf Anfrageprotokolle für OpenAI, OpenRouter, Anthropic, Gemini, Ollama und jeden kompatiblen Endpunkt, den du eintippst. Schlüssel bleiben auf dem Server. Funktioniert
  • quickreplies/ Schnellantworten Sets mit einer Knopfleiste über dem Eingabefeld: sieben Befehle, die sich verketten lassen, noch ohne Auto-Ausführung und Kontextmenüs. Teilweise
  • Import Aus einer anderen App importieren Den Datenordner einer anderen App durchsuchen, sehen, was gefunden wurde, und Charaktere, Chats, Lorebooks und Presets in einem Zug kopieren. Funktioniert

Wie eine Antwort entsteht

  1. Zusammenbauen Das Preset wird der Reihe nach gebaut, mit Persona, Charakter und Szenario an ihren Plätzen.
  2. Lore durchsuchen Lorebook-Schlüssel werden gegen den letzten Chat geprüft; Einschlussgruppen und Zeiteffekte entscheiden, was zündet.
  3. Token einteilen Der Kontext wird mit dem passenden Tokenizer für OpenAI-, Claude- und Gemini-Modelle auf das Budget gekürzt.
  4. Anbieter aufrufen Eine Anfrage an den aktiven Anbieter, in dem Protokoll, das dieser Anbieter spricht.
  5. Streamen Token kommen über SSE an. Der Server speichert die Nachricht, die Seite zeichnet sie nur.
—

Was noch fehlt

Das ist Software im frühen Zugang. Das sind die Lücken, die man vor der Installation kennen sollte.

  • Getippte Slash-Befehle und Skripte. Eine Zeile wie /send hello geht als Text an das Modell; nur Schnellantwort-Knöpfe führen Befehle aus.
  • Erweiterungen, die für andere Clients geschrieben wurden. Keine lädt.
  • Anhänge und Bildeingabe. Kein Datei-Upload und keine Bilder als Eingabe.
  • Vektor-Gedächtnis. Lange Chats werden auf das Budget gekürzt; die Zusammenfassung ist das einzige Langzeitgedächtnis.
  • macOS und Linux. Die Shell packt auf beiden und CI baut sie, veröffentlicht wird aber nur Windows, und gelaufen ist keines von beiden.
  • Ein unsigniertes Installationsprogramm. SmartScreen warnt einmal bei einer heruntergeladenen Kopie; nimm die Datei von der Release-Seite und von nirgendwo sonst.

Die vollständigen Listen stehen in Grenzen · Format-Kompatibilität.

Installieren

Windows

Lade das Installationsprogramm aus dem neuesten Release und führe es aus. Es installiert pro Benutzer, braucht keinen Administrator und kein eigenes Node und hält deine Daten in %APPDATA%\dev.catcup.tavern. Es ist unsigniert, deshalb warnt SmartScreen einmal und nennt keinen Herausgeber: wähle Mehr Informationen → Trotzdem ausführen.

Web oder LAN aus dem Quellcode

Braucht Node 22.13 oder neuer und pnpm 11. Beim ersten Start setzt du ein Zugangspasswort, und zwar nur auf dem Rechner, auf dem der Server läuft.

pnpm install
pnpm dev
CATCUP_HOST=0.0.0.0 pnpm start

Für ein LAN an alle Schnittstellen binden; das Passwort ist das einzige Tor. Danach http://localhost:5173 öffnen. TLS ist nicht eingebaut. Außerhalb eines vertrauenswürdigen Netzes gehört es hinter einen Reverse-Proxy oder ein VPN.

Eine Installation umziehen

CATCUP_DATA_DIR zeigt die App auf einen anderen Datenordner. So zieht eine Installation auf einen neuen Rechner um, und so übernimmt eine Desktop-Installation eine bestehende Bibliothek.
