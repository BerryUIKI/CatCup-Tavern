data/

你的数据就是文件

角色是元数据写在图片里的 PNG 卡，或者纯 JSON。聊天是 JSONL，一行一条消息，滑动候选和分支都在里面。世界书、预设和设置都是 JSON。备份就复制文件夹，换机器也复制文件夹，想改哪一处都可以直接用编辑器打开。

data/
├── characters/     角色卡，PNG 或 JSON
├── chats/          每段对话一个 JSONL
├── worlds/         世界书
├── presets/        提示词预设
├── groups/         群聊房间
├── user/images/    生成的图片
├── secrets.json    仅服务端保存的 API 密钥
└── settings.json   提供商、用户身份、档案

把导入器指向另一个应用的数据文件夹，角色卡、聊天、世界书和预设一步就能搬过来。没有任何东西被转换成本项目私有格式。

data/

它能做什么

  • data/characters/ 角色与群聊 支持 PNG、JSON V2/V3 与 CharX 角色卡。你可以只和一个角色说话，也可以把五个人放进一个房间，各带问候语、头像和发言顺序。 可用
  • data/worlds/ 世界书 主键与次键、递归、带权重的包含组、粘滞与冷却效果、Token 预算，以及每一种注入位置，外加一个能解释条目为何生效的检查器。 可用
  • data/presets/ 提示词预设 导入 OpenAI 预设，重排或停用某条提示词，也可以把一条挪进聊天注入，单独设定深度、顺序和角色。 可用
  • data/chats/ 对话与分支 流式回复，推理内容单独收纳；支持滑动候选、编辑，以及从任意一条消息分出分支，原对话原样保留。 可用
  • data/chats/ · summary 摘要记忆 滚动摘要就存在聊天文件里，紧挨着它所概括的消息。你可以直接改，也可以让它在每次回复后更新。 可用
  • user/images/ 语音与图片 浏览器语音，或任何兼容 OpenAI 的语音接口。图片可来自 Automatic1111、ComfyUI 或兼容 OpenAI 的接口，按角色分别保存。 可用
  • data/secrets.json 提供商 五种请求协议，覆盖 OpenAI、OpenRouter、Anthropic、Gemini、Ollama，以及你自己填写的任何兼容接口。密钥只留在服务端。 可用
  • quickreplies/ 快捷回复 快捷回复组会在输入框上方显示成按钮条：七个命令可以串联，暂时还没有自动执行和右键菜单。 部分可用
  • Import 从其他应用导入 扫描另一个应用的数据文件夹，先看清找到了什么，再一次性复制角色、聊天、世界书和预设。 可用

一条回复是怎么拼出来的

  1. 拼装 按预设的顺序组装提示词，用户身份、角色和场景各就各位。
  2. 扫描世界书 用世界书的键匹配最近的对话；包含组和定时效果决定哪些条目真正生效。
  3. 计算 Token 按模型预算裁剪上下文，OpenAI、Claude 和 Gemini 的模型各有对应的分词器。
  4. 请求提供商 向当前提供商发一次请求，用的就是它自己的协议。
  5. 流式返回 Token 通过 SSE 陆续到达。消息由服务端保存，页面只负责画出来。
—

暂时还没有的

这是早期体验版。下面这些缺口，建议你在安装之前先知道。

  • 手动输入的斜杠命令与脚本。像 /send hello 这样的一行会作为普通文字发给模型；只有快捷回复按钮会执行命令。
  • 为其他客户端写的扩展。一个都加载不了。
  • 附件与视觉输入。没有文件上传，也不能发图片。
  • 向量记忆。长对话会按预算裁剪，摘要是目前唯一的长期记忆。
  • macOS 与 Linux。外壳在两个平台上都能打包，CI 也会编译，但只发布了 Windows，而且这两个平台都没有实际运行过。
  • 安装包未签名。下载的副本会被 SmartScreen 警告一次；请只从发布页面获取安装文件。

install

安装

Windows

从最新发布页下载安装包并运行。按用户安装，不需要管理员权限，也不需要单独装 Node，数据保存在 %APPDATA%\dev.catcup.tavern。安装包未签名，所以 SmartScreen 会警告一次并且不显示发布者：选择“更多信息 → 仍要运行”。

下载安装包 直接下载：本版本的安装包，托管在 GitHub 上。

CatCup.Tavern_0.3.2_x64-setup.exe · 所有版本

从源码运行网页版或局域网版

需要 Node.js 22.13 或更新版本，以及 pnpm 11。首次运行时要设置访问密码，而且只能在运行服务端的这台机器上设置。

pnpm install
pnpm dev
CATCUP_HOST=0.0.0.0 pnpm start

要开局域网，就绑定所有网卡；密码是唯一的门槛。 然后打开 http://localhost:5173。 程序本身不带 TLS。出了可信网络，请放在反向代理或 VPN 后面。

迁移一份安装

用 CATCUP_DATA_DIR 把应用指向另一个数据目录。换机器时是这样搬，桌面版接管已有资料库也是这样。
