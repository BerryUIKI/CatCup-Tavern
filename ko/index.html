장부는 스스로 적는다.

한 사람과, 혹은 방을 채운 일행과. 세계관 설정, 프롬프트 프리셋, 롤링 요약, 음성과 이미지까지. 카드도 대화도 여러분 디스크 위의 평범한 파일입니다. 하나의 서버가 세 가지 모습을 띕니다: 브라우저 탭, LAN, Windows 앱.

data/

데이터는 파일 그대로

캐릭터는 메타데이터를 이미지 안에 품은 PNG 카드이거나 순수 JSON입니다. 채팅은 JSONL, 한 줄에 메시지 하나, 스와이프와 갈래까지 들어 있습니다. 세계관 설정과 프리셋, 설정은 JSON입니다. 백업하려면 폴더를 복사하고, 옮기려면 폴더를 복사하고, 고치고 싶은 곳은 편집기로 열면 됩니다.

data/
├── characters/     카드, PNG 또는 JSON
├── chats/          대화마다 JSONL 하나
├── worlds/         세계관 설정
├── presets/        프롬프트 프리셋
├── groups/         그룹 방
├── user/images/    생성한 이미지
├── secrets.json    API 키, 서버 전용
└── settings.json   제공자, 페르소나, 프로필

가져오기를 다른 앱의 데이터 폴더로 지정하면 카드, 채팅, 세계관 설정, 프리셋이 한 번에 넘어옵니다. 어느 것도 이 프로그램만의 형식으로 바뀌지 않습니다.

data/

무엇을 하는가

  • data/characters/ 캐릭터와 그룹 PNG, JSON V2/V3, CharX 카드. 한 사람과 이야기하거나, 다섯 명을 한 방에 넣고 각자의 인사말, 아바타, 발언 순서를 줄 수 있습니다. 지원
  • data/worlds/ 세계관 설정 주 키와 보조 키, 재귀, 가중치가 있는 포함 그룹, 끈적임과 쿨다운 효과, 토큰 예산, 그리고 모든 삽입 위치. 항목이 왜 발동했는지 보여 주는 검사기까지. 지원
  • data/presets/ 프롬프트 프리셋 OpenAI 프리셋을 가져오고, 프롬프트 순서를 바꾸거나 끄고, 하나를 채팅 내 삽입으로 옮겨 깊이·순서·역할을 따로 정할 수 있습니다. 지원
  • data/chats/ 채팅과 갈래 추론을 따로 받는 스트리밍 응답, 스와이프, 편집, 그리고 어느 메시지에서든 갈라지는 갈래. 원래 채팅은 그대로 남습니다. 지원
  • data/chats/ · summary 요약 기억 롤링 요약은 채팅 파일 안, 요약하는 메시지 바로 옆에 저장됩니다. 직접 고치거나 응답 뒤에 갱신하게 할 수 있습니다. 지원
  • user/images/ 음성과 이미지 브라우저 음성, 또는 OpenAI 호환 음성 엔드포인트. 이미지는 Automatic1111, ComfyUI, OpenAI 호환 엔드포인트에서 받아 캐릭터별로 보관합니다. 지원
  • data/secrets.json 제공자 다섯 가지 요청 프로토콜로 OpenAI, OpenRouter, Anthropic, Gemini, Ollama, 그리고 직접 입력한 호환 엔드포인트를 아우릅니다. 키는 서버에만 남습니다. 지원
  • quickreplies/ 빠른 답장 입력창 위 버튼 줄로 보이는 세트. 일곱 가지 명령을 이어 붙일 수 있지만 자동 실행과 상황 메뉴는 아직 없습니다. 일부 지원
  • Import 다른 앱에서 가져오기 다른 앱의 데이터 폴더를 훑어 무엇이 발견됐는지 보여 준 뒤, 캐릭터, 채팅, 세계관 설정, 프리셋을 한 번에 복사합니다. 지원

답장 한 편이 만들어지는 과정

  1. 조립 프리셋 순서대로 프롬프트를 세우고 페르소나, 캐릭터, 상황을 제자리에 넣습니다.
  2. 세계관 훑기 세계관 키를 최근 대화와 맞춰 보고, 포함 그룹과 시간 효과가 무엇이 발동할지 정합니다.
  3. 토큰 배분 OpenAI, Claude, Gemini 모델에 맞는 토크나이저로 문맥을 모델 예산에 맞춰 자릅니다.
  4. 제공자 호출 활성 제공자에게 요청 한 번. 그 제공자가 쓰는 프로토콜 그대로 보냅니다.
  5. 스트리밍 토큰은 SSE로 도착합니다. 메시지는 서버가 저장하고, 페이지는 그리기만 합니다.

아직 없는 것

초기 액세스 소프트웨어입니다. 설치 전에 알아 두면 좋은 빈틈입니다.

  • 직접 입력하는 슬래시 명령과 스크립트. /send hello 같은 줄은 그냥 글자로 모델에 갑니다. 명령을 실행하는 것은 빠른 답장 버튼뿐입니다.
  • 다른 클라이언트용 확장. 하나도 불러오지 않습니다.
  • 첨부와 이미지 입력. 파일 업로드도 이미지 전송도 없습니다.
  • 벡터 기억. 긴 대화는 예산에 맞춰 잘리고, 장기 기억은 요약 하나뿐입니다.
  • macOS와 Linux. 둘 다 패키징되고 CI도 컴파일하지만 공개된 것은 Windows뿐이며, 둘 다 실제로 실행해 본 적은 없습니다.
  • 서명되지 않은 설치 파일. 내려받은 사본은 SmartScreen이 한 번 경고합니다. 파일은 오직 릴리스 페이지에서 받으세요.

CatCup.Tavern_0.3.2_x64-setup.exe · 모든 릴리스

소스에서 웹·LAN 실행

Node.js 22.13 이상과 pnpm 11이 필요합니다. 첫 실행 때 접속 비밀번호를 정하며, 서버를 돌리는 컴퓨터에서만 정할 수 있습니다.

pnpm install
pnpm dev
CATCUP_HOST=0.0.0.0 pnpm start

LAN으로 쓰려면 모든 인터페이스에 바인딩하세요. 관문은 비밀번호 하나입니다. 그런 다음 http://localhost:5173 을 여세요. TLS는 내장되어 있지 않습니다. 신뢰하는 네트워크 밖에서는 리버스 프록시나 VPN 뒤에 두세요.

설치 옮기기

CATCUP_DATA_DIR로 데이터 폴더를 다른 곳으로 돌릴 수 있습니다. 다른 컴퓨터로 옮길 때도, 데스크톱 앱이 기존 라이브러리를 이어받을 때도 이 방법입니다.
